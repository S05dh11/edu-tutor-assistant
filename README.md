# AI学科辅导助手 - RAG + Multi-Agent增强版

> 基于魔珐星云数字人SDK的智能K12教育辅导系统，采用RAG检索增强和Multi-Agent协作框架，提供高准确度、低幻觉率的学科辅导服务。支持**数学公式LaTeX渲染**，实现专业级数学排版显示。

**代码仓库**: https://github.com/S05dh11/edu-tutor-assistant

## 项目简介

本项目参加**魔珐星云具身智能黑客松 2025** - AI实时交互教育赛道。

### 核心特性

- **数字人实时交互**: 基于3D数字人形象，提供沉浸式学习体验
- **数学公式渲染**: 集成KaTeX库，支持LaTeX数学公式专业排版显示
- **RAG知识库检索**: 内置13个精心编写的学科知识点，确保回答准确可靠
- **Multi-Agent协作**: 5个专业AI Agent协同工作，降低幻觉率
- **多学科支持**: 覆盖数学、语文、英语、物理四大主科
- **智能分段播放**: 自动处理长文本朗读，分段延迟优化至10ms
- **多场景教学**: 支持教育教学、培训演练、考核测试、学习评估、口语陪练五大场景
- **对话历史记忆**: 保留最近10轮对话，AI能理解上下文
- **中文朗读优化**: 数字、符号、LaTeX公式自动转换为可读中文（60+符号映射）

### Multi-Agent框架

```
用户提问
    ↓
┌─────────────────────────────────────────┐
│  Multi-Agent 协作系统                    │
├─────────────────────────────────────────┤
│ 🔍 检索Agent → 从知识库检索相关内容       │
│    ↓                                    │
│ 🧠 分析Agent → 分析问题类型和复杂度       │
│    ↓                                    │
│ 📋 设计Agent → 设计教学策略和回答结构     │
│    ↓                                    │
│ ✏️ 生成Agent → 基于RAG上下文生成回答      │
│    ↓                                    │
│ ✅ 验证Agent → 验证答案准确性和安全性     │
└─────────────────────────────────────────┘
    ↓
最终回答（高准确度、低幻觉率）
```

### RAG知识库系统

- **内置知识库**: 13个专业知识点，覆盖核心考点
- **智能检索**: 基于关键词匹配和相关性评分
- **上下文增强**: 将检索到的知识注入AI提示词
- **可扩展**: 支持用户自定义知识点

## 功能说明

### 数学公式渲染

系统集成了KaTeX数学公式渲染引擎，支持专业的数学排版显示。

#### 支持的LaTeX格式

| 格式 | 示例 | 渲染效果 |
|------|------|----------|
| 行内公式 | `$a^2 + b^2 = c^2$` | a² + b² = c² |
| 独立公式 | `$$\frac{-b \pm \sqrt{b^2-4ac}}{2a}$$` | 完整求根公式 |
| 上标/下标 | `$x^2$`, `$H_2O$` | x², H₂O |
| 根号 | `$\sqrt{x}$` | √x |
| 分数 | `$\frac{a}{b}$` | a/b |
| 希腊字母 | `$\alpha$`, `$\pi$` | α, π |
| 求和/积分 | `$\sum_{i=1}^{n}$`, `$\int$` | ∑, ∫ |

#### AI输出格式

AI会自动使用LaTeX格式输出数学公式，例如：

```
勾股定理的公式是：$a^2 + b^2 = c^2$，其中$a$和$b$是直角边，$c$是斜边。

一元二次方程的求根公式是：
$$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$$
```

#### 语音朗读优化

系统会自动将LaTeX公式转换为可朗读的中文：

| LaTeX | 朗读 |
|-------|------|
| `$a^2 + b^2 = c^2$` | "a的二 加 b的二 等于 c的二" |
| `$\sqrt{25}$` | "根号二十五" |
| `$\frac{1}{2}$` | "二分之一" |
| `$\pi$` | "派" |
| `$\alpha$` | "阿尔法" |

### 场景模式

系统提供5种教学模式，覆盖完整的教学流程：

| 场景 | 图标 | 描述 | 快捷问题 |
|------|------|------|----------|
| 教育教学 | 📚 | 知识讲解与概念解析 | 讲解这个知识点、举例说明、有什么记忆技巧？、今日总结 |
| 培训演练 | 📝 | 例题演示与解题技巧 | 出一道例题、分析解题思路、有哪些易错点？、今日总结 |
| 考核测试 | 📋 | 出题测试与答案解析 | 出题考考我、我刚才答对了吗？、详细解析这道题、今日总结 |
| 学习评估 | 📊 | 学习进度与能力评估 | 评估我的学习情况、我哪里需要加强？、给出学习建议、今日总结 |
| 口语陪练 | 🗣️ | 英语口语对话练习 | How are you?、Introduce yourself、Tell me about your hobby、今日总结 |

| 英语 | 小英 | 语法、词汇、口语、写作 | 3个 |

### AI模式切换

- **Multi-Agent增强模式**（默认）: 使用RAG和Multi-Agent，回答更准确
- **基础模式**: 纯AI对话，响应更快

点击"切换AI模式"按钮可切换模式。

### 对话历史

- 系统自动保留最近10轮对话历史
- AI能理解上下文，例如：
  - AI出题：`a = 3, b = 4, 求a+b = ?`
  - 用户回复：`a + b = 7`
  - AI会判断答案正确并给予肯定

点击"清空记录"按钮可同时清空对话历史。

### 知识库管理

点击"知识库"按钮可查看所有学科的知识点内容。

### Markdown格式支持

对话区域支持以下Markdown格式：

| 格式 | 语法 | 效果 |
|------|------|------|
| 加粗 | `**文本**` | **粗体** |
| 斜体 | `*文本*` | *斜体* |
| 删除线 | `~~文本~~` | ~~删除~~ |

### 中文朗读优化

系统自动将数字和符号转换为中文发音（60+符号映射）：

| 符号 | 中文 | 符号 | 中文 |
|------|------|------|------|
| 1+2=3 | 一加二等于三 | % | 百分之 |
| 50% | 百分之五十 | ° | 度 |
| x^2 | x的二乘方 | √ | 根号 |
| ∞ | 无穷大 | π | 派 |
| → | 趋向于 | ∫ | 积分 |

**LaTeX公式自动转换**：
- `$a^2$` → "a的二"
- `$\sqrt{x}$` → "根号x"
- `$\frac{a}{b}$` → "b分之a"
- `$\pi$` → "派"

**Markdown符号自动清理**：
- `**` `*` - 加粗/斜体符号
- `~~` - 删除线符号
- `` ` `` - 代码符号
- `#` - 标题符号

这些符号会在朗读前自动移除，不会被读出来。

## 常见问题

### Q: 数学公式没有渲染，显示原始代码？
A:
1. 确保已刷新页面（Ctrl+F5）
2. 检查浏览器控制台是否有KaTeX加载错误
3. 确认AI输出使用了正确的LaTeX格式（`$...$` 或 `$$...$$`）

### Q: 数字人显示不全？
A: 数字人位置已优化，如需调整可修改 `css/style.css` 中的 `top` 值。

### Q: 朗读不完整？
A: 系统使用SDK的语音结束回调触发分段播放，分段延迟已优化至10ms。

### Q: 如何提高回答准确度？
A: 使用Multi-Agent模式，系统会自动检索知识库并使用多Agent验证。

### Q: AI不记得之前说的话？
A: 系统自动保留10轮对话历史，如需清空请点击"清空记录"按钮。

### Q: 出题总是重复？
A: 已优化随机性参数(temperature=0.7)，每次出题会自动变化。

### Q: LaTeX符号被读出来怎么办？
A: 系统已自动转换LaTeX命令为中文，包括 `\sqrt` → "根号"、`\frac` → "分数"等。

### Q: 公式显示样式不对？
A:
- 助手消息中的公式：蓝色高亮
- 独立公式：灰色背景框，左侧蓝色边框
- 用户消息中的公式：白色样式适配蓝色背景
