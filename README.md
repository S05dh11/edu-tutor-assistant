# AI学科辅导助手 - RAG + Multi-Agent增强版

> 基于魔珐星云数字人SDK的智能K12教育辅导系统，采用RAG检索增强和Multi-Agent协作框架，提供高准确度、低幻觉率的学科辅导服务。

**代码仓库**: https://github.com/S05dh11/edu-tutor-assistant

## 项目简介

本项目参加**魔珐星云具身智能黑客松 2025** - AI实时交互教育赛道。

### 核心特性

- **数字人实时交互**: 基于3D数字人形象，提供沉浸式学习体验
- **RAG知识库检索**: 内置20+精心编写的学科知识点，确保回答准确可靠
- **Multi-Agent协作**: 5个专业AI Agent协同工作，降低幻觉率
- **多学科支持**: 覆盖数学、语文、英语、物理四大主科
- **智能分段播放**: 自动处理长文本朗读，流畅自然
- **多场景教学**: 支持教育教学、培训演练、考核测试、学习评估、口语陪练五大场景

### Multi-Agent框架

```
用户提问
    ↓
┌─────────────────────────────────────────┐
│  Multi-Agent 协作系统                    │
├─────────────────────────────────────────┤
│ 🔍 检索Agent → 从知识库检索相关内容       │
│    ↓                                    │
│ 🧠 分析Agent → 分析问题类型和复杂度       │
│    ↓                                    │
│ 📋 设计Agent → 设计教学策略和回答结构     │
│    ↓                                    │
│ ✏️ 生成Agent → 基于RAG上下文生成回答      │
│    ↓                                    │
│ ✅ 验证Agent → 验证答案准确性和安全性     │
└─────────────────────────────────────────┘
    ↓
最终回答（高准确度、低幻觉率）
```

### RAG知识库系统

- **内置知识库**: 20+专业知识点，覆盖核心考点
- **智能检索**: 基于关键词匹配和相关性评分
- **上下文增强**: 将检索到的知识注入AI提示词
- **可扩展**: 支持用户自定义知识点

## 快速开始

### 1. 获取密钥

- **魔珐星云密钥**: 访问 [魔珐星云官网](https://xingyun3d.com/) 注册并创建应用
- **魔搭API Key**: 访问 [魔搭社区](https://modelscope.cn/) 获取API密钥

### 2. 本地运行

```bash
# 启动本地服务器
node server.js

# 访问 http://localhost:8001
```

### 3. 配置密钥

1. 点击"密钥配置"按钮
2. 填入AppId、AppSecret和API Key
3. 点击"保存配置"

### 4. 开始使用

1. 选择场景（教育教学、培训演练、考核测试、学习评估、口语陪练）
2. 选择学科（数学、语文、英语、物理）
3. 点击"连接AI老师"
4. 输入问题或点击快捷问题开始学习

## 功能说明

### 场景模式

系统提供5种教学模式，覆盖完整的教学流程：

| 场景 | 图标 | 描述 | 适用场景 |
|------|------|------|---------|
| 教育教学 | 📚 | 知识讲解与概念解析 | 学习新知识、理解概念 |
| 培训演练 | 📝 | 例题演示与解题技巧 | 掌握解题方法、练习技能 |
| 考核测试 | 📋 | 出题测试与答案解析 | 检验学习效果、巩固知识 |
| 学习评估 | 📊 | 学习进度与能力评估 | 了解薄弱环节、制定计划 |
| 口语陪练 | 🗣️ | 英语口语对话练习 | 提高英语口语、日常交流 |

### 学科切换

支持4个学科，每个学科有专属的辅导风格：

| 学科 | 老师名字 | 擅长领域 | 知识点数量 |
|------|----------|----------|------------|
| 数学 | 小理 | 代数、几何、函数、统计 | 4个 |
| 语文 | 小文 | 阅读、古诗文、作文 | 3个 |
| 英语 | 小英 | 语法、词汇、口语、写作 | 3个 |
| 物理 | 小物 | 力学、电磁学、光学、实验 | 3个 |

### AI模式切换

- **Multi-Agent增强模式**（默认）: 使用RAG和Multi-Agent，回答更准确
- **基础模式**: 纯AI对话，响应更快

点击"切换AI模式"按钮可切换模式。

## 技术亮点

### 1. RAG检索增强

- 精确匹配学科知识点
- 多维度相关性评分
- 知识库内容实时注入AI提示词

### 2. Multi-Agent协作

- **检索Agent**: 从知识库获取权威知识
- **分析Agent**: 理解问题类型和复杂度
- **设计Agent**: 制定最优教学策略
- **生成Agent**: 基于RAG上下文生成回答
- **验证Agent**: 多维度质量检查

### 3. 低幻觉率设计

- 知识库约束：优先使用内置知识
- 多层验证：Agent协作交叉检验
- 答案评分：低于60分自动改进

### 4. 多场景教学系统

- **教育教学**: 系统化知识讲解，概念定义+关键要点+记忆技巧
- **培训演练**: 例题演示，分析考查点+展示步骤+总结方法
- **考核测试**: 出题测试，一次一题+等待回答+判断对错+解析
- **学习评估**: 能力评估，知识掌握+理解水平+学习建议
- **口语陪练**: 英语对话，简单英语+语法纠正+地道表达+鼓励练习

### 5. 流畅交互体验

- 流式响应显示
- 智能分段朗读
- 实时Agent状态面板
- 字幕同步显示

## 开发指南

```javascript
KnowledgeBase.addCustomTopic('math', {
    title: '新知识点',
    keywords: ['关键词1', '关键词2'],
    content: '详细的知识内容...'
```

### 自定义Agent

在 `agents.js` 中添加新的Agent逻辑：

```javascript
const AgentSystem = {
    AGENTS: {
        myagent: {
            name: '我的Agent',
            icon: '🤖',
            description: 'Agent描述',
            color: '#000000'
        }
    }
};
```

## 常见问题

### Q: 数字人显示不全？
A: 数字人位置已优化到85%，如需调整可修改 `css/style.css` 中的 `top` 值。

### Q: 朗读不完整？
A: 系统使用SDK的语音结束回调触发分段播放，请检查控制台日志确认回调是否正常触发。

### Q: 如何提高回答准确度？
A: 使用Multi-Agent模式，系统会自动检索知识库并使用多Agent验证。
