  ## ✨ 项目简介

  本项目是一个基于 **魔珐星云数字人SDK** 和 **魔搭社区AI模型** 的K12学科辅导系统。

  ### 核心理念
  > 星云让 AI 拥有"老师的身体与对话能力"，把学习从"看内容"升级为一个能实时对话、能引导学习、能陪练的AI老师。

  ### 主要功能
  - 🎭 **3D数字人互动** - 实时渲染的AI老师形象
  - 💬 **智能对话** - 接入魔搭AI大模型，流式响应
  - 📚 **多学科支持** - 数学、语文、英语、物理
  - ⚡ **快捷问题** - 预置高频学习问题
  - 🔊 **语音播放** - 数字人语音合成与口型同步
  - 📝 **字幕显示** - 实时字幕，方便阅读

  ## 🚀 快速开始

  ### 环境要求
  - Node.js 14+
  - 现代浏览器 (Chrome 90+ / Edge 90+ / Safari 14+)

  ### 安装与运行

  1. **克隆或下载项目**
  ```bash
  cd edu-tutor-assistant

  2. 启动本地服务器
  node server.js

  3. 访问应用
  http://localhost:8001

  ⚠️ 注意: 必须通过 HTTP 服务器访问，不能直接打开 index.html 文件（file:// 协议会导致音频功能无法使用）

  ---
  🔑 密钥配置

  获取密钥

  | 密钥                  | 获取地址                         | 用途      |
  |-----------------------|----------------------------------|-----------|
  | 数字人 AppId & Secret | https://xingyun3d.com/developers | 数字人SDK |
  | 魔搭 API Key          | https://modelscope.cn/           | AI对话    |

  配置步骤

  1. 打开应用后点击 "密钥配置" 按钮
  2. 填写三个密钥：
    - 数字人 AppId
    - 数字人 AppSecret
    - 魔搭 API Key
  3. 点击 "保存配置"

  ---
  📖 使用指南

  基本操作

  1. 连接AI老师
    - 配置好密钥后，点击 "连接" 按钮
    - 等待资源下载完成（首次约需30-60秒）
    - 连接成功后，AI老师会自我介绍
  2. 选择学科
    - 点击顶部学科按钮切换：数学 / 语文 / 英语 / 物理
    - 每个学科有不同的辅导老师和知识库
  3. 开始对话
    - 在输入框输入问题，点击发送或按回车
    - 也可以点击快捷问题按钮
    - AI老师会语音回答问题

  学科介绍

  | 学科    | 老师名字 | 擅长领域               |
  |---------|----------|------------------------|
  | 📐 数学 | 小理     | 代数、几何、函数、统计 |
  | 📖 语文 | 小文     | 阅读理解、古诗文、作文 |
  | 🔤 英语 | 小英     | 语法、词汇、口语、写作 |
  | ⚛️ 物理 | 小物     | 力学、电磁学、光学     |

  🐛 常见问题

  Q: 数字人没有声音？

  A:
  - 确保通过 http://localhost:8001 访问，不能直接打开html文件
  - 检查浏览器是否允许音频播放
  - 查看控制台是否有 "PCMAudioPlayer" 相关错误

  Q: 连接失败，提示 "会话初始化失败"？

  A:
  - 检查密钥是否正确
  - 确认魔珐星云应用中是否选择了角色
  - 确认应用状态是否为"已启用"

  Q: 提示 "房间限流"？

  A:
  - 点击"断开连接"
  - 等待3-5秒后刷新页面
  - 重新连接

  Q: 数字人渲染不出来？

  A:
  - 检查浏览器是否支持WebGL
  - 尝试刷新页面
  - 查看控制台网络连接状态
